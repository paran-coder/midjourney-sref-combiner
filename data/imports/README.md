# SREF Import 폴더

이 폴더의 `.txt` 파일이 SREF 데이터 원본입니다.

## 새 데이터 추가

새 TXT 파일을 이 폴더에 넣기만 하면 됩니다.

예:

```text
--sref 3186922520
--sref 1636187491 2354286329
--sref 2921367196 --niji 7
--sref 1235558871::1 --niji 7
--sref 3623850304 --v 8.1
--sref 4371870492 --profile op2hwq1
```

빌드 시 `scripts/build-sref-db.mjs`가 모든 `.txt` 파일을 파일명 순서로 읽어 통합합니다.

- 동일 코드는 최종 DB에서 자동 중복 제거
- 같은 코드가 여러 번 나온 출현 기록은 모두 보존
- `::weight`, `--niji`, `--v`, `--profile` 메타데이터 보존
- 원본 파일명과 행 번호 보존

`.md` 파일은 import 대상이 아니므로 이 안내 문서는 DB에 영향을 주지 않습니다.
